Ce qu'il te faut

  • Minecraft Java Edition sur ordinateur (Windows, Mac ou Linux), avec le launcher officiel.
  • Un compte Discord : il est obligatoire pour jouer sur le serveur.
  • Bedrock, consoles et téléphones ne marchent pas. Le serveur est uniquement en Java Edition.
1

Installe Fabric 26.2

Fabric permet à Minecraft de charger des mods. Ferme d'abord Minecraft et le launcher.

  1. Télécharge l'installateur Fabric sur le site officiel.
    • Windows : prends la version .exe (Download for Windows). Pas besoin d'installer Java.
    • Mac et Linux : prends la version .jar (Universal/.JAR). Il faudra peut-être installer Java pour l'ouvrir.
  2. Ouvre l'installateur. Dans l'onglet Client, choisis Minecraft Version : 26.2 et laisse la Loader Version proposée.
  3. Garde la case Create profile cochée, puis clique sur Install.
Télécharger l'installateur Fabric

Sur Mac : si Apple bloque le fichier, va dans Réglages Système, Confidentialité et sécurité, puis clique sur « Ouvrir quand même ».

2

Lance Fabric une première fois

  1. Ouvre le launcher Minecraft.
  2. À gauche du bouton Jouer, choisis le profil fabric-loader-26.2.
  3. Clique sur Jouer, attends le menu principal, puis quitte le jeu.

Ce premier lancement crée le dossier mods dont tu vas avoir besoin juste après.

3

Télécharge les 3 mods

Sur chaque page Modrinth, vérifie que le fichier est bien pour Fabric et 26.2.

1

Mielon's The Sift 2.0 Fabric 26.2

Le mod du serveur. Prends la même version que le serveur, annoncée sur le Discord.

mielon's-the-sift-2.0.x-mc26.2-fabric.jar
Télécharger
2

GeckoLib 5.5.5

Nécessaire au mod du Sift. Il faut exactement la version 5.5.5 pour Fabric 26.2.

geckolib-fabric-26.2-5.5.5.jar
Télécharger
3

Fabric API 26.2

Aussi nécessaire au mod du Sift. Prends la dernière version pour 26.2.

fabric-api-0.xxx.x+26.2.jar
Télécharger

Attention : les versions Forge ou NeoForge ne marchent pas. Garde les fichiers en .jar et ne les décompresse pas.

4

Mets-les dans le dossier mods

Ouvre le dossier mods de Minecraft, puis glisse les 3 fichiers .jar dedans.

  1. Appuie sur Windows + R.
  2. Colle cette adresse, puis appuie sur Entrée :
    %appdata%\.minecraft\mods
  1. Dans le Finder, ouvre le menu Aller, puis Aller au dossier…
  2. Colle cette adresse, puis appuie sur Entrée :
    ~/Library/Application Support/minecraft/mods
  1. Ouvre ton gestionnaire de fichiers et va dans ce dossier :
    ~/.minecraft/mods
.minecraft/ └─ mods/ ├─ mielon's-the-sift-2.0.x-mc26.2-fabric.jar ├─ geckolib-fabric-26.2-5.5.5.jar └─ fabric-api-0.xxx.x+26.2.jar

Le dossier mods n'existe pas ? Crée-le toi-même dans .minecraft et nomme-le exactement mods, en minuscules.

5

Lance le jeu

  1. Ouvre le launcher et choisis le profil fabric-loader-26.2.
  2. Clique sur Jouer. Si le jeu arrive au menu principal sans erreur, tes mods sont bien installés.
6

Ajoute le serveur

  1. Dans le menu, clique sur Multijoueur, puis Ajouter un serveur.
  2. Remplis les deux champs comme ci-dessous, puis clique sur Terminé.
  3. Double-clique sur Sift SMP dans la liste pour te connecter.

Problèmes fréquents

Le jeu plante au lancement

Un mod manque ou n'est pas à la bonne version. Vérifie que tu as bien les 3 fichiers, tous pour Fabric 26.2, et que GeckoLib est en 5.5.5. Supprime aussi les anciennes versions en double dans le dossier mods.

Le profil Fabric n'apparaît pas dans le launcher

Relance l'installateur Fabric en gardant « Create profile » coché, puis redémarre complètement le launcher.

Je ne trouve pas le dossier mods

Lance une fois le profil fabric-loader-26.2 (étape 2). Sinon, crée un dossier nommé mods dans .minecraft.

Mes fichiers sont en .zip

Le navigateur ou toi les avez sans doute renommés ou décompressés. Supprime-les et retélécharge les fichiers .jar depuis Modrinth.

Je n'arrive pas à me connecter au serveur

Vérifie l'adresse fr.siftsmp.xyz. Le serveur ouvre mi-décembre : avant, c'est normal qu'il ne réponde pas. Sinon, demande de l'aide sur le Discord.

J'utilise Modrinth App, CurseForge ou un autre Launcher Moddé

Crée une instance Fabric en 26.2, puis ajoute les mêmes 3 mods. Vérifie bien que GeckoLib est en 5.5.5 pour Fabric, car l'appli peut proposer une autre version.

Toujours bloqué ? Demande de l'aide sur le Discord ou écris à contact@siftsmp.xyz.
