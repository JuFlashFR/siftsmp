Comment rejoindre

Le mod est nécessaire pour te connecter.

  1. Installe Fabric pour Minecraft 26.1.2.
  2. Télécharge Mielon's the Sift sur Modrinth et place le fichier dans ton dossier mods.
  3. Lance Minecraft avec le profil Fabric, puis ajoute le serveur fr.siftsmp.xyz.
